Inspect a profile's resolved executable and arguments without launching it:

```bash
go run ./cmd/scripts/print_args.go <profile-id>
```

An explicit profile ID is required; the utility does not select a workstation
profile by default.

## Architecture documentation

[OpenWiki quickstart](../openwiki/quickstart.md) links to architecture, services,
operations and testing. These pages are generated by the scheduled OpenWiki
workflow, not hand-maintained. Source code, tests and current CLI help take
precedence when a generated page drifts. In particular, older pages may still
list eleven backend kinds, old help fixtures or a retired root audit path;
there are twelve kinds in the current domain registry, including `strata`.

## History is not an operating recipe

[Dated reports and evidence](reports/README.md) preserve experiments, negative
results, frozen manifests and archived plans. Hardware measurements, absolute
paths and profile availability describe the date of the experiment. Do not
execute an archived prompt or installation recipe as current authorization.
Use the maintained guides above for current commands.
